# Gemini Next.js Starter

Aplikasi Next.js (App Router) terintegrasi dengan Google Gemini API menggunakan SDK resmi `@google/genai`.

## Cara Menjalankan

1. **Buka folder proyek di terminal:**
   ```bash
   cd C:\Users\Asus\.gemini\antigravity\scratch\gemini-nextjs
   ```

2. **Instal dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   ```

4. **Buka di browser:**
   [http://localhost:3000](http://localhost:3000)
